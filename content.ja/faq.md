[[faq]]
  q = "99 Nights in the Forest は無料で遊べますか？"
  a = "はい。Roblox の無料ゲームで、採取・建築・防衛のループも救出クエストも全部無料です。一部クラスとコスメはジェムか Robux が要りますが、コア進行が有料で囲われていることはありません。"

[[faq]]
  q = "どのプラットフォームで遊べますか？"
  a = "Roblox が動く場所ならどこでも——PC、Mac、iOS、Android、Xbox。進行は Roblox アカウントに紐づくので、端末を変えても消えません。"

[[faq]]
  q = "最大で何人で遊べますか？"
  a = "2〜4人のチームが前提の設計で、そこが快適帯です。群れの攻撃と鹿はソロの徘徊者を潰しに来ますし、手が増えれば木切り・建築・夜警を分担できます。"

[[faq]]
  q = "ソロでもクリアできますか？"
  a = "できます。ただし難易度は跳ね上がります。ソロの人は序盤を1〜2日伸ばし、夜に徘徊せず、正々堂々の戦闘ではなく罠とカイトに頼ってください。焚き火は早めにレベル2へ。広い光の半径がソロの一番の相棒です。"

[[faq]]
  q = "友達と一緒に遊ぶにはどうしますか？"
  a = "同じ Roblox サーバーに入るだけです。フレンドリストから友達のゲームに参加するか、サーバーの招待リンクを共有してください。全員揃ったら一緒に焚き火を建てます。"

[[faq]]
  q = "このゲームは映画が原作ですか？"
  a = "20世紀スタジオの映画タイアップがあり、それで新規プレイヤーが大量に流入しています。ゲーム自体は Grandma's Favourite Games 製作の Roblox 協力サバイバルです。"

[[faq]]
  q = "行方不明の子供はどう救出しますか？"
  a = "掲示板がクエストを起動し、赤い矢印がマップを横切るように示します。各救出は守護者戦で締まり、その後で子供を焚き火まで運びます。4人全員救出＋焚き火の拡張が、1夜あたり約8日分の進行スキップルートです。"

[[faq]]
  q = "コードの大文字小文字は関係ありますか？"
  a = "いいえ。綴りさえ正確なら——`yay fishing` の中のスペースも含めて——大文字小文字は自由に混ぜて通ります。"

[[faq]]
  q = "yay fishing が自分だけ動きません。なぜですか？"
  a = "条件が三つあります。焚き火レベル2、釣り竿が実際に釣り場の水に刺さっていること、単語のあいだのスペース。一つでも欠けると2ダイヤモンドは永遠に来ません。火がレベル1なら、あなたのゲームではそのコードがまだ存在していません。"

[[faq]]
  q = "今いくつコードは生きていますか？"
  a = "10月3日の検証時点で4つです。ロビー入力の `awardwinner_yay`、`forestwakesup26`、`afterparty` と、チャットコードの `yay fishing`。合計47ダイヤモンド分の無料予算になります。生きているリストは [コードのページ](/codes) にあります。"

[[faq]]
  q = "焚き火と作業台、どっちを先に上げますか？"
  a = "焚き火をレベル2、そのあと作業台をレベル2、そのあと焚き火をレベル3です。レベル2の火は釣りルートと安全な光の半径を解放し、作業台はその後の採取を全部倍にします。全理由は [焚き火の強化ページ](/guide/campfire-upgrades) に。"

[[faq]]
  q = "新規プレイヤーはどのクラスを選べばいいですか？"
  a = "最初は無料のキャンパーでループを覚えて、そのあとメディックかランバージャックを買ってください。メディックの回復と蘇生はどの武器より夜の決着を左右し、ランバージャックが木材経済の全部を回します。"

[[faq]]
  q = "うちの壁を壊すのは何ですか？"
  a = "ラムです。木の柵をまっすぐ突き破ってきます。修理用の木材を拠点の内側から届く場所に置いて、彼がどのレーンを選ぶか見ていてください——アイツは道を一つ選ぶとそこに決めます。"

[[faq]]
  q = "動物はテイムできますか？"
  a = "できます。レベル3のテイマーズフルート＋サーモン5、ステーキ5、カボチャ5で、一番有用な相棒であるクマを懐かせられます。オオカミはスキップ推奨——検証の結果、キャンプで仕事を引かないことが分かっています。"

[[faq]]

ゲームの初心者ですか？ ここが、ロビーと受信トレイで繰り返し聞かれる質問の受け皿です。当サイトは、サバイバルゲームにありがちな一般論の水増しではなく、プレイヤーが実際に投げる質問——どの強化を先にするか、チャットコードがなぜ支払いを拒むのか、行方不明の子供クエストが実際何なのか、Forest Rage がルールをどう変えるのか——に絞って並べています。

スクロールの前に二つだけ枠組みを置いておきます。一つ目、このゲームのコードはスケジュールで動いていません——パッチにぶら下がってやって来るので、夏から更新されていないコードリストは死んだ文字列を生きているように見せます。当サイトの [コードページ]({{< relref "/codes" >}}) は意図的に検証日を見える位置に置き、失効表を併設して、本物と偽物を見分けられるようにしています。二つ目、序盤には誰も教えてくれないでかい解放が一つあります——焚き火レベル2が釣りルートを開き、その釣りルートこそが `yay fishing` を本物にします。新人の大半はロビーチャットにそれを打ち込んで何ももらえず、リストが間違っていると結論づけます。間違っていません。

どの脅威が何夜目に出るかの質問なら [モンスター対策ガイド]({{< relref "/monsters" >}}) が敵の時間割です。拠点のレイアウトの話なら [最初の10夜]({{< relref "/guide/first-10-nights" >}}) から入ってください。どこにも載っていない質問があれば、そのための [お問い合わせ]({{< relref "/legal/contact" >}}) です——届いたメッセージは全部読み、良い質問はこのリストに追加しています。

なお、ここに並べた Q&A はロビーのチャットや編集部の受信トレイで実際に繰り返し聞かれたものだけを採用しています。「ゲームと映画どっちが先？」みたいな一般論や、どの攻略サイトにもある汎用のQ&Aは意図的に外しました。数字が絡む質問には10月3日検証時点の数値をそのまま書いているので、コードの有効期限やダイヤの合計額は日付の古い記事コメントを鵜呑みにせず、[コードのページ]({{< relref "/codes" >}}) の表で最新を確認してください。
