初期クラスはいまや10種類で、サバイバルチームが必要とする仕事——木材・食料・治療・偵察・戦闘・逃走——を全部カバーしています。9月の変更がここでは超大きいです。9月5日に Woodsman、Escape Artist、Elemental がデイリークエストと火の捧げ物付きで実装され、9月19日の Class Shop Revamp で全クラスがローテーション待ちなしの常時販売になりました。つまり古い「並ぶのを待つ」という作戦は死んでいます。ショップに見えているものが、今日買えるものです。

## 10職をひと目で

| クラス | 役割 | 選ぶ理由 |
|---|---|---|
| キャンパー | バランス初期 | 無料、弱点なし、まずループを覚える |
| メディック | 治療と蘇生 | 全滅と立て直しの分かれ目 |
| ランバージャック | 木材経済 | 速い伐採が全部の強化を支える |
| スカベンジャー | 補給 | 食料とスクラップを切らさない |
| クック | 食料加工 | 長期ランの食費を安くする |
| レンジャー | 探索 | マップを埋め、手がかりを追う |
| アサシン | 瞬間火力 | 高火力、紙装甲、手癖の良い人専用 |
| ウッズマン | 木材経済その2 | 専用斧ウッズマンズ・アックス持ち、丸太保管・巨木苗特典 |
| エスケープ・アーティスト | 生存逃走 | ダッシュ、追跡逃走、探知特典 |
| エレメンタル | バイオーム支援 | バイオームヘルメット、状態異常、速度、暗視 |

## 役割の内訳

**メディック**は地味な最強職です。治療と蘇生はどんな武器より夜の結果を左右し、まともなチームなら一人は欲しいところです。

**ランバージャック**と**ウッズマン**は両方が木材エンジンで、しかも重ねられます。ランバージャックは最初から木切りが速い。ウッズマンは専用のウッズマンズ・アックスを初期装備として持ち込み、保管と巨木苗の特典まで付いてきます。二人両方を回すチームは、拠点建設フェーズがスプリントになります。

**スカベンジャー**と**クック**は支援経済です。スカベンジャーが補給を回し、クックが食べ物を長期ランの安い燃料に変える。どちらも、包囲の途中で食料が尽きるまで静かに仕事をしていることに気づけません。

**レンジャー**は探索と救出フェーズ、つまり壁を守るよりマップを埋めることが大事な局面で真価を発揮します。

**アサシン**は遊ぶと楽しい職で、同時に一番習熟度が要ります。瞬間火力は本物で、被弾の許容範囲が紙なのも本物。初めて買う職として選ぶ新人はだいたい値段を後悔します。

**エスケープ・アーティスト**と**エレメンタル**は9月5日組です。エスケープ・アーティストのクエストは、アルファウルフ7匹に同時追跡されるという内容で——良いクエストであり、理不尽な試練です。エレメンタルのクエストは、50体の異なる敵に毒・氷・火を付与することを要求します。どちらも条件が噛み合うと強く、噛み合わないと普通です。

## チームでの選び方

俺たちが繰り返し言っているルールがこれです——**メディックがゼロのチームは、全滅を志願しているようなもの**。そのあとは、木材エンジンを一人（ランバージャックかウッズマン）、支援を一人（スカベンジャーかクック）、最後の枠をそのランが求めるもので埋めてください——救出を急ぐならレンジャー、ループを既に知っているならアサシン。

バニー（イースターショップでエッグ900個）、エッグハンター、エルフ、エイリアンサイエンティスト（600ダイヤモンドの解除が明示されている）といったイベント限定クラスは、イベントやジェムショップに並びます。追う価値はありますが、コアの10職ではありません。
