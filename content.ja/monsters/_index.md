99夜を生き延びる半分は、これから自分の拠点に歩いて来る相手を知ることです。ゲームは「ラムが何夜目に来るか」「鹿がなぜ突然昼に出るのか」「カルティストが実は3〜4日周期で襲撃タイマーを回している」といった大事なことを一切教えてくれません。このページは敵図鑑です——各脅威が何をするのか、いつ出るのか、木材を一番使わない対処は何か、をまとめます。

## 脅威一覧

| 脅威 | 危険度 | 実際の仕事 |
|---|---|---|
| 鹿 | 極大 | 看板ナイトストーカー。焚き火を回り、闇に出た人を刈る |
| カルティスト | 高 | 3〜4日周期で集団キャンプを襲撃 |
| カルティストキング | ボス | 襲撃チェーンから出現。遠隔カイトボス |
| クマ／シロクマ | 高 | 頂点。弱い装備を一瞬で咎める |
| アルファウルフ | 高 | 群れの長。ソロ探索者を殺しに来る |
| ラム | 高 | 木の壁を破壊する突撃役 |
| オオカミ | 中 | 群れ狩り。焚き火の外で危ない |
| フクロウ | 中 | 光源を邪魔してくる |
| コウモリ | 低 | 洞窟の群れ。単体は弱いが地下では多い |
| 雪バイオームの動物 | 中 | 露出したプレイヤーに凍結デバフを押し付ける |

## 各戦闘の短い答え

- **鹿**は正々堂々の戦闘を望んでいません。光の半径を回って隙を待ちます。コミュニティの検証で、進行度に連動した隠しスケーリングが見つかっていて、それがナイト30の鹿がナイト3の鹿とは別物に感じる理由です。重い夜にはカルティストを指揮してきます。全解説は [鹿のページ]({{< relref "/monsters/deer" >}}) に。
- **カルティストはタイマーで襲ってきます。** 毎晩ではなく、だいたい3〜4日周期、しかも集団はどんどん大きくなります。壁が彼らを罠に誘い込み、コミュニティのキルファネル迷路拠点はこの襲撃を500日以上 farming して耐えています。
- **ラム**は戦闘ではなく壁の問題です。柵をまっすぐ突き破ります。修理木材を輪の内側に置き、彼が選ぶレーンを見てください。
- **オオカミ**は群れで狩り、ソロ探索者をバラバラにします。5夜を過ぎたらペアで動いてください。
- **クマ**は序盤の「手を出すな」枠です。コミュニティのライフル検証で各動物を仕留める弾数が測られていますが、新人チームへの総括はストレートで——弱いライフルはオオカミ相手でマガジンの大半を消費し、クマならさらに大量です。武器が追いつくまで、クマはカイトと罠の問題です。
- **コウモリ**は焚き火レベル3で解放される洞窟に住んでいます。懐中電灯、食料、ライフルを持ち、地下で自分を追い詰めないでください。

## 各敵はいつ出るのか

序盤の目安はこうです。鹿と小さなカルティストの圧力は初夜から、オオカミと壁破りのラムは5夜以降の中盤、クマは後半の脅威、フクロウと雪・洞窟の敵はそれぞれのバイオームを探索して初めて開きます。夜の湧きは生き延びた夜数に連動してスケールするので、ナイト10で耐えた拠点が全く同じレイアウトでナイト30に失敗する、というのが普通に起きます。

{{< notice title="ゲーム内で確認" >}}出現パターンとバランスはアプデと難易度設定で動きます。この危険度は現行パッチの当サイトの読み物で、固定の時刻表ではありません。{{< /notice >}}
