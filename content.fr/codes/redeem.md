La plupart des codes de 99 Nights in the Forest s'échangent dans le **lobby** en quatre taps. Un seul code — **yay fishing** — ne marche nulle part près du lobby, et quasiment chaque nouveau joueur l'essaie d'abord là-bas, n'obtient rien, et conclut que la liste est fausse. Cette page te promène les deux méthodes et les modes d'échec dont personne ne te parle.

## Échanger les codes du lobby

1. **Lance le jeu et reste dans le lobby.** Ne rejoins pas un serveur pour l'instant. La fenêtre d'échange vit uniquement dans le menu du lobby, ce qui piège pas mal de gens en pleine partie qui avaient tapé le code dans le chat en jeu.
2. **Ouvre le menu gemmes** — clique sur l'**icône diamant** dans le **coin inférieur gauche** de l'écran. Elle est à côté des autres boutons de devises, pas dans la roue des réglages.
3. **Ouvre la fenêtre des codes** — appuie sur le bouton bleu **Codes** dans le **coin inférieur droit** de ce menu.
4. **Tape le code exactement comme listé** et valide avec **Submit**.
5. Regarde ton compteur de gemmes grimper. Les codes qui donnent aussi des Flames (les trois Flames de `awardwinner_yay`, ceux de `forestwakesup26`) les ajoutent immédiatement à ton écran de collection — ouvre ton équipement pour vérifier.

{{< notice >}}Les codes ne sont **pas sensibles à la casse** — `AfterParty` marche aussi bien que `afterparty`. L'orthographe doit rester exacte, et l'espace à l'intérieur de `yay fishing` est obligatoire. Si un code est expiré, le jeu dit invalide ou déjà utilisé. Cette erreur veut dire que le code est mort, pas que ton clavier est cassé.{{< /notice >}}

## Le seul code qui refuse le lobby : yay fishing

`yay fishing` paie 2 gemmes et refuse de marcher ailleurs qu'en pleine partie. Le rituel complet :

1. **Monte ton feu de camp au niveau 2.** C'est la porte cachée. Sans feu niveau 2, la route de la canne à pêche n'existe pas, et le code de chat reste mort, peu importe comment tu le tapes. C'est pour ça que tant de joueurs jurent que le code est un fake.
2. **Fabrique la canne à pêche** et va à un point de pêche.
3. **Lance la canne pour qu'elle soit bien dans l'eau.** Debout sur la berge, ça ne compte pas.
4. Appuie sur **/** pour ouvrir le chat et tape exactement :

   `yay fishing`

5. Presse Entrée. Deux gemmes apparaissent instantanément.

L'espace entre les mots est exigé. La canne dans l'eau est exigée. Le feu niveau 2 est exigé. Fais les trois et ça marche à chaque coup, ce qui en fait un excellent test pour savoir si ton installation de pêche est en ligne avant d'y passer une soirée.

## Pourquoi un code peut échouer avec une orthographe correcte

Quand l'orthographe est bonne mais que la récompense ne tombe pas, vérifie dans cet ordre :

- **Tu es dans un serveur, pas dans le lobby** — pour chaque code de lobby, le menu n'existe simplement pas.
- **Le code est saisonnier.** `happyhalloween` a marché pour l'événement Halloween 2025 et est mort depuis. Les codes d'événement meurent quand l'événement se termine ; regarde le tableau des expirés sur l'[index des codes]({{< relref "/codes" >}}).
- **Le code a été retiré tôt.** Ça arrive. Le wiki communautaire et notre [journal des mises à jour]({{< relref "/updates" >}}) sont là où on poste le retrait ; une liste qui n'a pas bougé depuis l'été l'affichera encore comme en vie.
- **Tu l'as déjà utilisé.** Les codes, c'est un échange par compte. Renvoyer la même commande donne une erreur plate.

## Quels codes valent vraiment le coup maintenant

À notre vérification du 3 octobre, les codes en vie sont `awardwinner_yay` (15 gemmes plus trois Flames), `forestwakesup26` (15 gemmes plus trois Flames), `afterparty` (15 gemmes) et `yay fishing` (2 gemmes). Additionne, et un compte tout neuf peut démarrer une run avec 47 gemmes de budget gratuit, ce qui achète beaucoup de marge avant le premier week-end double gemmes.

## Le rapport entre codes et mises à jour

Les codes de ce jeu arrivent accrochés aux patchs, pas sur un planning. La refonte de la Class Shop du 19 septembre a lâché `awardwinner_yay` le jour même de l'annonce du week-end double gemmes, et l'événement Forest Wakes Up du 13 juin a lâché `forestwakesup26`. Le coup pratique : après chaque note de patch, scanne à la recherche d'une chaîne de code avant d'ouvrir YouTube, parce que les miniatures vidéo ont au moins quelques heures de retard sur le vrai lâcher.

## Quoi faire des gemmes que tu viens de toucher

Quarante-sept gemmes gratuites, ce n'est pas de la monnaie de poche pour un compte neuf. Le coup le plus rentable de la boutique actuelle, c'est d'économiser jusqu'au prochain week-end double gemmes — ces week-ends tombent autour des coups de projecteur comme le prix du meilleur jeu de survie aux Roblox Innovation Awards 2026, et chaque gemme que tu possèdes déjà double pendant la fenêtre de l'événement. Ne dépense pas le solde gratuit dans un cosmétique le jour même.

La moitié Flames des récompenses compte tout autant. Un code qui paie des gemmes *et* trois Flames, c'est en réalité un coupon de mise à niveau d'équipement, et les Flames, c'est ce que tu ne peux pas farmer de façon fiable sur le terrain avant le milieu de run. Vérifie la page [Flames modifieuses et offrandes de feu]({{< relref "/advanced/modifier-flames" >}}) avant d'en coller une sur un outil de départ, parce que c'est le classique moyen de gâcher toute la récompense.

## Le problème des faux codes

La moitié des vidéos YouTube « nouveaux codes » pour ce jeu sont des reupload de chaînes expirées depuis des mois, bourrées de codes inventés pour paraître à jour. Si une vidéo promet un code qu'on ne liste pas, recoupe l'[index des codes]({{< relref "/codes" >}}) avant de taper quoi que ce soit dans le lobby — un faux code ne te coûte rien, mais un « générateur de codes » qui te demande ta connexion, si.
