La plupart des codes de『99 Nights in the Forest』s'échangent dans le**lobby** en quatre étapes. Un seul code spécial——**yay fishing**——fonctionne différemment, expliqué en bas de page.

## Échanger les codes du lobby

1. **Lance le jeu** et reste dans le lobby. N'entre pas encore dans un serveur.
2. **Ouvre le menu boutique/gemmes** — clique sur l'**icône diamant** en**bas à gauche** de l'écran.
3. **Ouvre la fenêtre de codes** — appuie sur le bouton bleu **Codes** en**bas à droite** de ce menu.
4. **Entre le code exactement** et clique sur**Submit**.
5. La récompense (gemmes, flames, etc.) arrive immédiatement — vérifie ton solde.

{{< notice >}}Les codes**ne distinguent pas les majuscules**, mais l'orthographe doit être exacte — y compris l'espace dans **yay fishing**. Si un code a expiré, le jeu dira simplement invalide ou déjà utilisé. C'est comme ça qu'on sait qu'il a expiré (et non qu'on s'est trompé). {{< /notice >}}

## Le code de chat spécial : yay fishing

**yay fishing** ne s'échange pas dans le lobby. Pour obtenir ses 2 gemmes :

1. **Monte le feu de camp au niveau 2**.
2. **Fabrique/obtiens une canne à pêche**.
3. Va à un point de pêche et lance la canne pour que l'hameçon**entre dans l'eau**.
4. Appuie sur **/** pour ouvrir le chat et tape :

   `yay fishing`

5. Appuie sur Entrée — les 2 gemmes apparaissent aussitôt.

L'espace entre "yay" et "fishing" est obligatoire. Tu peux essayer sur n'importe quel point de pêche, canne dans l'eau.

## Pourquoi les codes expirent

Les développeurs retirent les codes avec les mises à jour du jeu pour garder l'économie de récompenses équilibrée. Quand un code expire, on le déplace dans l'**archive des codes expirés** de la [page codes](/codes/), pour que personne ne perde son temps avec des listes obsolètes d'autres sites.
