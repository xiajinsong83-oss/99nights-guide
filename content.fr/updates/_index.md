Cette page suit chaque mise à jour de 99 Nights in the Forest — nouvelles classes, événements, badges, structures et codes. Elle se rafraîchit automatiquement toutes les 12 heures depuis la page officielle Roblox et le journal de mises à jour communautaire : vous y voyez donc généralement les nouveautés le jour même du patch.

{{< notice title="Comment cette page se met à jour" >}}Une GitHub Action exécute <code>scripts/auto_update.py</code> toutes les 12 heures : elle récupère la page officielle Roblox et le journal communautaire, ajoute les nouveautés à <code>data/updates.yaml</code>, puis Cloudflare Pages reconstruit automatiquement. Seules de nouvelles entrées sont ajoutées — rien n'est jamais supprimé automatiquement ici.{{< /notice >}}
