Most codes in 99 Nights in the Forest are redeemed in the **lobby** in four taps. One code — **yay fishing** — works nowhere near the lobby, and nearly every new player tries it there first, gets nothing, and assumes the list is wrong. This page walks through both methods and the failure modes nobody tells you about.

## Redeeming lobby codes

1. **Launch the game and stay in the lobby.** Do not join a server yet. The redemption box only lives in the lobby menu, which catches a lot of people mid-run who typed the code into in-game chat.
2. **Open the gem menu** — click the **diamond icon** in the **bottom-left corner** of the screen. It sits next to the other currency buttons, not in the settings gear.
3. **Open the codes window** — press the blue **Codes** button in the **bottom-right** of that menu.
4. **Type the code exactly as listed** and hit **Submit**.
5. Watch your Diamond balance tick up. Codes that also grant Flames (like `awardwinner_yay`'s three Flames and `forestwakesup26`'s three) add them to your collection screen immediately — open your loadout to check.

{{< notice >}}Codes are **not case-sensitive** — `AfterParty` works as well as `afterparty`. The spelling must still be exact, and the space inside `yay fishing` is mandatory. If a code is expired, the game says invalid or already used. That error means the code is dead, not that your keyboard is broken.{{< /notice >}}

## The one code that refuses the lobby: yay fishing

`yay fishing` pays out 2 Diamonds and it refuses to work anywhere except inside a live run. The full ritual:

1. **Upgrade your campfire to level 2.** This is the hidden gate. Without a level 2 fire, the fishing rod route does not exist, and the chat code stays dead no matter how you type it. This is why so many players swear the code is fake.
2. **Build the fishing rod** and head to a fishing spot.
3. **Cast the rod so it actually sits in the water.** Standing on the bank does not count.
4. Press **/** to open chat and type exactly:

   `yay fishing`

5. Press Enter. Two Diamonds spawn instantly.

The space between the words is required. The rod being in the water is required. The level 2 fire is required. Do all three and it works every time, which is what makes it such a good test of whether your fishing setup is live before you spend an evening on the water.

## Why a code might fail on a correct spelling

When the spelling is right but the reward does not land, check these in order:

- **You are in a server, not the lobby** — for every lobby code, the menu simply is not there.
- **The code is seasonal.** `happyhalloween` worked for the 2025 Halloween event and is dead now. Event codes die when the event ends; check the expired table on the [Codes index]({{< relref "/codes" >}}).
- **The code was pulled early.** It happens. The community wiki and our [Updates log]({{< relref "/updates" >}}) are where we post the pull; a list that has not been touched since summer will still show it as live.
- **You already used it.** Codes are one redemption per account. Re-submitting gives a flat error.

## How codes relate to updates

Codes in this game arrive attached to patches, not on a schedule. The September 19 Class Shop Revamp dropped `awardwinner_yay` the same day it announced the 2x Diamond weekend, and the June 13 Forest Wakes Up event dropped `forestwakesup26`. The practical move: after every patch note, scan for a code string before you open YouTube, because the video thumbnails lag the actual drop by hours at minimum.

## What to do with the Diamonds you just claimed

Forty-seven free Diamonds is not pocket change for a fresh account. The highest-value move in the current shop is saving through the next 2x Diamond weekend — those weekends land around award moments like the Roblox Innovation Awards 2026 Best Survival Game win, and every Diamond you already own doubles for the event window. Do not spend the free balance on a cosmetic the day it arrives.

The Flames half of the rewards matter just as much. A code that pays out Diamonds *and* three Flames is effectively a gear-upgrade coupon, and Flames are the thing you cannot grind reliably in the field until mid-run. Check the [Modifier Flames & Fire Offerings]({{< relref "/advanced/modifier-flames" >}}) page before you attach one to a starter tool, because that is the classic way to waste the whole reward.

## The fake-code problem

Half the YouTube "new codes" videos for this game are reuploads of strings that expired months ago, padded with invented codes to look current. If a video promises a code we do not list, cross-check the [Codes index]({{< relref "/codes" >}}) before typing anything into the lobby — a fake code costs you nothing, but a "code generator" that asks for your login does.
