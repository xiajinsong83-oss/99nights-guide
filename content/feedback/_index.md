Guides are written once and used for months, which means they rot the second the game patches them. Player feedback is how we stop that rot: a code that quietly died, a wall that now behaves differently, an upgrade cost that moved after the Class Shop Revamp. Everything that lands in the inbox gets read, checked against the current patch, and either fixed on the page or noted here.

## How feedback gets handled

- **You send it.** Use the form below and hit Send — it opens your email app with the message pre-filled, so nothing gets lost in a submit button.
- **We verify it.** A claim like "this code no longer works" gets checked in the lobby before we touch the codes table. Opinions about which class feels weakest get weighed but not treated as balance data.
- **It gets published, or it does not.** Useful comments pass moderation and appear on this page with the next update. Messages containing personal attacks, spam or anything unrelated to the guides get answered privately instead of published.
- **No accounts, no tracking.** Sending feedback does not create an account. The message reaches us by email and we use it only to respond and improve the site.

## What the comments here look like

The comments currently on display are marked as **examples** — they show how real feedback threads read on this site, not the full backlog. As the archive grows, you will see corrections, requests for new guides (we read those closely), and the occasional report that a strategy from one of our pages broke a run.

## What to send

- **Corrections first.** A wrong number, a dead code, a tip that no longer works. This is the highest-value feedback there is.
- **What you want next.** Tell us which biome, class or event you need covered and we will queue it.
- **Video submissions.** If you made a walkthrough that belongs in the [video archive]({{< relref "/media" >}}), send the link.
