## What this video actually shows

Picking a class in 99 Nights is a real commitment — classes cost gems and change how your run plays — and this video does the unpopular job: it tests the classes one by one to find which ones drag a run down. The run goes class by class through the roster, putting each through the same survival situations, with Fisherman and Hunter getting direct attention alongside the rest. The payoff is a judgment per class rather than a tier list in words: you see where each perk actually helps at the bonfire, on a hunt, and against the night.

## Key takeaways

- **Worst-class testing assumes identical runs.** The value comes from comparing classes under the same pressure — the same night defense, the same resource pressure. Watch the comparisons, not the intro.
- **Fisherman and Hunter get direct scrutiny.** A fishing economy and hunting perks look good on paper; the video tests whether they actually carry a run or just feel nice while they last.
- **A bad class hurts at the start, not forever.** The interesting moments are the early nights, where a weak economy perk costs you the campfire upgrade race.
- **Use it as a buy-avoid list.** The practical output is which classes are safe gem spending and which are traps — more useful than any text summary, because you see the struggle instead of reading about it.
