This page tracks every game update for 99 Nights in the Forest — new classes, events, badges, structures and codes. It refreshes automatically every 12 hours from the official Roblox game page and the community update log, so what you see here usually lands the same day the patch does.

{{< notice title="How this page updates" >}}A GitHub Action runs <code>scripts/auto_update.py</code> every 12 hours: it fetches the official Roblox page and the community update log, appends new updates to <code>data/updates.yaml</code>, and Cloudflare Pages rebuilds automatically. Only new entries are added — nothing here is ever deleted automatically.{{< /notice >}}
