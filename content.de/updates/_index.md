{{< notice title="So aktualisiert sich diese Seite" >}}Eine GitHub Action führt alle 12 Stunden <code>scripts/auto_update.py</code> aus: Sie holt die offizielle Roblox-Seite und das Community-Log, fügt neue Updates zu <code>data/updates.yaml</code> hinzu, und Cloudflare Pages baut automatisch neu. Es werden nur neue Einträge ergänzt — nichts wird hier automatisch gelöscht.{{< /notice >}}
