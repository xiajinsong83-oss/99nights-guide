Forest Rage는『99 Nights in the Forest』의 하드 모드 층입니다——메인 플레이 이후에 진입하며, 위협 성장을 끌어올리고 부패 메커니즘, 균열 정화, 연구 전초기지라는 엔드게임 목표를 추가합니다.

{{< notice title="집필 중" >}}이 가이드는 집필 대기열에 있습니다——아래 시스템은 확정된 방향(부패 / 균열 정화 / 연구 전초기지)이고, 구체적 수치와 전략은 검증 중입니다. 당분간 전부 틀 콘텐츠로 취급하세요. {{< /notice >}}

## Forest Rage에서 바뀌는 것

- **위협 성장**——몬스터가 더 세게, 더 일찍, 더 빠르게.
- **부패**——부패 구역이 지도에 퍼지며 관리가 필요.
- **균열**——균열 정화가 부패를 되밀어내는 방법.
- **연구 전초기지**——하드 모드 루프를 묶는 엔드게임 목표.

## 준비 방법

1. 들어가기 전에**모닥불과 작업대를 최대로 강화**——하드 모드는 약한 코어를 벌합니다.
2. **나무와 음식을 2배 비축**——일반 플레이의 두 배가 필요.
3. **일찍 Modifier Flames 수집**——[Flames]({{< relref "/advanced/modifier-flames" >}})가 하드 모드의 진짜 데미지 배율.
4. **팀으로**——하드 모드 솔로는 혹독합니다.

## 하드 모드 루프 (틀)

1. **낮**：가장자리 부패를 정화하고, 채집, 강화.
2. **해질녘**：기지를 봉쇄——하드 모드의 밤은 더 세고 영리하게 공격.
3. **균열 창**：균열이 활성화되면 돌격팀이 정화해 부패 압력을 낮춤.
4. **전초기지**：연구 전초기지에서 수리와 연구로 최종 목표를 진행.
