유일한 '최강 직업'은 없습니다——하지만**당신의 상황**에 최강 직업은 있습니다. 이 티어리스트는 전형적인 팀 플레이 기여도로 7개 시작 직업을 나열하고, 솔로용 메모도 달았습니다.

{{< notice title="의견이지 절대 기준이 아님" >}}이것은 현재 직업 역할에 기반한 커뮤니티 의견 순위입니다. 밸런스 패치로 직업이 계층을 옮길 수 있습니다——이유가 순위 자체보다 중요합니다. {{< /notice >}}

## 티어리스트

### S — 메타
- **메딕**——치료와 부활은 전멸과 재기 사이의 갈림길. 진심인 팀은 하나쯤 꼭.
- **럼버잭**——나무 경제가 기지 전체를 받칩니다. 빨리 베면 모닥불과 작업대 강화가 빨라집니다.

### A — 강하고 유연
- **스캐빈저**——보급 운반이 루프를 계속 돌게 합니다; 전투 중심 팀에서는 약간 약함.
- **쿡**——장기 플레이에서 음식 압박은 실재적; 짧은 세션에서는 활약이 적음.

### B — 상황에 따라
- **레인저**——탐험과 구출 단계에서 빛나지만, 순수 방어의 밤에는 평범.
- **어쌔신**——숙련자에겐 재밌고 강하지만, 초보자에겐 물렁함.

### C — 학습용
- **캠퍼**——처음에는 충분하지만, 루프에 익숙해지면 밀립니다.

## 상황별 최선의 선택

| 상황 | 최선 | 이유 |
|---|---|---|
| 초보자 | 캠퍼 | 무료·밸런스·함정 없음 |
| 소팀 (2–3명) | 럼버잭 + 메딕 | 목재 엔진 + 회복 |
| 풀팀 (4명+) | 럼버잭 + 메딕×2 + 스캐빈저 | 경제 + 치료 |
| 하드 모드 (Forest Rage) | 메딕 + 어쌔신 | 생존 + 순간 화력 |
| 솔로 | 스캐빈저 | 자급자족 수집 |
| 스피드런 / 구출 중심 | 레인저 | 지도 전체 |

## 유일한 철칙

**팀에 메딕이 0명이면 절대 안 됩니다.** 치료는 어떤 단일 요소보다 밤의 결과를 좌우합니다.
