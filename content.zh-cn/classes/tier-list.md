没有唯一的"最强职业"——但存在适合**你的处境**的最强职业。这份强度榜按对典型小队旅程的贡献给 7 个初始职业排名，并附单人玩法说明。

{{< notice title="观点而非定论" >}}这是基于当前职业定位的社区观点排名。平衡补丁可能让职业在梯队间移动——下面的理由比名次本身更重要。{{< /notice >}}

## 强度榜

### S — 版本答案
- **医疗兵**——治疗与复活是团灭与恢复的分界线。每个认真的小队都想要一个。
- **伐木工**——木材经济支撑整个基地。砍得快，篝火和工作台升级就快。

### A — 强而灵活
- **拾荒者**——补给运输让循环不停转；在战斗向小队中稍弱。
- **厨师**——长跑时食物压力真实存在；短局里用处较小。

### B — 看情况
- **游侠**——探索与营救阶段闪耀，纯防守夜表现平庸。
- **刺客**——高手手里好玩又强力，但新手太脆。

### C — 学习工具
- **营火者**——开局完全没问题，但熟悉循环后就被比下去了。

## 按情况的最佳选择

| 情况 | 最佳选择 | 理由 |
|---|---|---|
| 新手 | 营火者 | 免费、均衡、无坑 |
| 小队（2–3 人） | 伐木工 + 医疗兵 | 木材引擎 + 续航 |
| 满编小队（4 人+） | 伐木工 + 2×医疗兵 + 拾荒者 | 经济 + 治疗 |
| 困难模式（Forest Rage） | 医疗兵 + 刺客 | 生存 + 爆发输出 |
| 单人 | 拾荒者 | 自给自足的搜刮 |
| 速通 / 营救向 | 游侠 | 地图覆盖 |

## 唯一铁律

**你的小队永远不能没有医疗兵。** 治疗对夜晚结局的影响超过任何单一因素。
