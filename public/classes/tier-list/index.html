Best Class in 99 Nights in the Forest — Tier List (Community)

Community tier list for 99 Nights in the Forest classes: which starter class is best for solo, for squads, for new players and for hard mode — with reasoning.

Home/ Class Compendium — All 7 Starter Classes in 99 Nights in the Forest/ Best Class in 99 Nights in the Forest — Tier List (Community)
Last updated: September 30, 2026

There is no single “best class” — but there is a best class for your situation. This tier list ranks the 7 starter classes by how much they contribute to a typical squad run, with notes for solo play.

⚠️ Opinion, not gospel: This is a community opinion ranking based on the current class roles. Balance patches can move classes between tiers — the reasoning below matters more than the letter.

Tier list

S — Meta picks

  • Medic — healing and revives are the difference between a wipe and a recovery. Every serious squad wants one.
  • Lumberjack — the wood economy runs the whole base. Fast chopping compounds into faster campfire and bench upgrades.

A — Strong and flexible

  • Scavenger — supply running keeps the loop moving; weaker in combat-heavy squads.
  • Cook — food pressure is real on long runs; less useful in short sessions.

B — Situational

  • Ranger — shines in exploration and rescue phases, mediocre in pure defense nights.
  • Assassin — fun and strong in skilled hands, but glassy for new players.

C — Learning tool

  • Camper — perfectly fine to start, but outclassed once you know the loop.

Best picks by situation

SituationBest pickWhy
New playerCamperFree, balanced, no traps
Small squad (2–3)Lumberjack + MedicWood engine + sustain
Full squad (4+)Lumberjack + 2×Medic + ScavengerEconomy + healing
Hard mode (Forest Rage)Medic + AssassinSurvival and burst damage
SoloScavengerSelf-sufficient looting
Speedrun / rescue focusRangerMap coverage

The one rule

Your squad should never have zero Medics. Healing decides night outcomes more than any other single factor.
