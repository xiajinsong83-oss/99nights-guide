Einlösen

So löst du Codes in der Lobby ein

1

Starte das Spiel und bleib in der Lobby

2

Klicke auf das Diamantsymbol unten links

3

Drücke die blaue Codes-Schaltfläche unten rechts

4

Gib den Code ein und drücke Submit zum Einlösen
