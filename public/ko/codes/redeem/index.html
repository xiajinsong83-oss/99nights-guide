99 Nights in the Forest 코드 입력 방법

『99 Nights in the Forest』코드 입력 단계별 가이드: 로비 다이아몬드 아이콘, Codes 버튼, 특별한 yay fishing 채팅 코드 방법.

홈/ 99 Nights in the Forest 코드 (2026년 10월)/ 99 Nights in the Forest 코드 입력 방법
최종 업데이트: September 30, 2026

『99 Nights in the Forest』의 대부분 코드는로비에서 네 단계로 입력할 수 있습니다. 특별한 코드 하나——yay fishing——만 방법이 다르며, 이 페이지 하단에서 설명합니다.

로비 코드 입력

  1. 게임을 시작하고 로비에 머뭅니다. 아직 서버에는 들어가지 마세요.
  2. 상점/보석 메뉴 열기——화면왼쪽 아래의다이아몬드 아이콘을 클릭.
  3. 코드 창 열기——그 메뉴오른쪽 아래의 파란 Codes 버튼을 누릅니다.
  4. 코드를 정확히 입력하고Submit을 누릅니다.
  5. 보상(보석, 플레임 등)은 즉시 지급됩니다——잔액을 확인하세요.
⚠ Note: 코드는대소문자를 구분하지 않지만 철자는 정확해야 합니다——yay fishing의 공백까지 포함해서요. 만료된 코드를 입력하면 게임은 ‘유효하지 않음’ 또는 ‘이미 사용됨’이라고만 표시합니다. 그게 입력 실수가 아니라 만료의 신호입니다.

특별 채팅 코드: yay fishing

yay fishing은 로비에서 입력할 수 없습니다. 보석 2개를 얻으려면:

  1. 모닥불을 레벨 2로 올린다.

  2. 낚싯대를 제작/획득.

  3. 낚시터로 가서 낚싯대를물속에던진다.

  4. / 를 눌러 채팅을 열고 입력:

    yay fishing

  5. Enter를 누르면——보석 2개가 즉시 나타납니다.

“yay"와 “fishing” 사이의 공백이 필수입니다. 낚싯대가 물에 들어간 상태라면 어느 낚시터에서든 시도할 수 있습니다.

코드가 왜 만료되나요

개발자는 보상 경제의 균형을 유지하기 위해 게임 업데이트와 함께 코드를 폐기합니다. 코드가 만료되면 코드 페이지의만료 코드 보관소로 옮겨서, 다른 사이트의 낡은 목록에서 시간을 낭비하지 않도록 합니다.
